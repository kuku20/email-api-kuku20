# Slack Monthly Job

### Setup

1. Create a new Slack workspace.
2. Create a new Slack app using the provided manifest:
   [Slack App Manifest](https://discord.com/channels/719617187563962409/1487221564645572770/1542279638745882764?utm_source=chatgpt.com)
3. copy SLACK_BOT_TOKEN, SLACK_USER_TOKEN and set to env
4. set SLACK_BOT_TOKEN to get bot ID
5. set SLACK_USER_TOKEN and run create channel [Create channels](src/slack/slack.service.ts)

6. [Turn on BULL BEAR](src/stock/task_bull_bear.service.ts)
    set local for test interactive (/interactive-messages?)
    [url](https://email-api-kuku20-production.up.railway.app/)
7. Sent all delete to all channel, sent btn for watching 
8. set SLACK_BOT_TOKEN

9. update on [rail](https://railway.com/) and [koyebw](https://www.koyeb.com/)
